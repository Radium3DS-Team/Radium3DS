## **Things to know:**

Rosalina menu is opened by L + Select (can use the orginal L, down, and select too)
Luma Menu when booting up (Now Radium Menu) is opened up by pressing D-Pad Up when starting.

## **How to Get Radium3DS**
Follow https://www.3ds.hacks.guide/ in order to get Lumas3DS (You can follow either
method, doesnt matter) and then you are going to download the boot.firm, and put it onto the ROOT of your SD card. (If it says this file already exists, Click overwrite or replace anyway, this is supposed to happen)
then turn off  your 3ds, and boot it back up while holding D-Pad Up. If it goes into Radium menu, you have successfully installed Radium.


### **Things to know (Installation):**
If a black screen pops up and you DO NOT have a old 3ds, please dm gg.kit on discord.
If a black screen pops up and gg.kit CANNOT fix the issue: Resort back to luma: open up the radium (luma) menu, and check the 'Boot vanilla luma' box to temporarily boot you back into luma (until you go back into radium menu. 
this will boot you into Lumas3DS as normal. This is for troubleshootinng

Another thing:
Radium uses an installation method I call "Partial Install" a Partial Install
is where it only replaces Luma on the SD card, so if you boot without an SD card, you
will boot into Vanilla Luma once again.
